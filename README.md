## 🚀 Featured Projects

### 📋 [Request Hub](https://github.com/lloydismael/request-hub)
A **role-based request and activity management platform built on Django** — coordinate engineering work, enforce SLA timelines, and get operational visibility from a single web portal.

- Request lifecycle with reference codes, priority levels, engagement types, and product categories
- **Engineer capacity enforcement** (max 5 ongoing requests; max 3 during an active deployment)
- **Automatic SLA due-date calculation** with overdue detection and RAG indicators
- Operational &amp; activity reporting — requests by engineer/requestor, billable vs non-billable hours
- Azure Communication Services email notifications, in-app notification center, SQR approval workflow
- Glass-morphism UI with dark mode, role-aware dashboards, fully responsive
- Dockerized and released under immutable version tags

`Django` · `Python` · `Docker` · `Azure` · `Chart.js`

---

### 💰 [Azure CSP Billing Portal](https://github.com/lloydismael/csp-billing)
A **FastAPI portal for Cloud Solution Providers** to ingest large Azure usage exports, apply customer-specific pricing strategies, and share interactive consumption dashboards.

- Streams **100–300 MB CSV exports** to disk, compresses to Parquet, queries via **DuckDB + Polars**
- Dynamic financial columns — forex adjustments, margin controls, VAT calculation
- Interactive Tabulator grid with search, filtering, column visibility, pagination, CSV export
- Dashboards for top customers, daily spend trends, and configurable billing summaries
- Role-based access (admin uploads / analyst read) and container-ready for App Service

`FastAPI` · `DuckDB` · `Polars` · `SQLite` · `Docker` · `Chart.js`

---

### 🏫 [LDP Portal](https://github.com/lloydismael/LDP)
A **Django records and management system for the Philippine Leadership Development Program** — tracking partner schools, scholars, awardees, principals, activities, and professionals.

- School profiles with hero banners, member rosters, and award tracking
- Dashboard with entity counters, recent activity feed, and pending approvals
- Dark-mode optimized UI, Dockerized deployment on Azure App Service

`Django` · `Python` · `Docker` · `Azure App Service`

### 🌐 [Portfolio](https://github.com/lloydismael/Portfolio) — [lloydismael.com](https://lloydismael.com)
A **100% Python build pipeline** portfolio: a Jinja2 static-site generator architected for **Azure Static Web Apps**, with a Python **Azure Functions** API powering the contact form.

- Liquid-glass design with persistent light/dark mode
- Live GitHub activity embed, Devicon-based technology iconography
- CI/CD to Azure Static Web Apps via GitHub Actions — no Node build step

`Python` · `Jinja2` · `Azure Static Web Apps` · `Azure Functions` · `GitHub Actions`

### 🔐 [File Portal](https://github.com/lloydismael/Portal)
A **secure Flask file-sharing portal** with authentication and **automatic QR code generation** for every uploaded file.

- Hashed-password auth, session management, login-gated uploads
- Timestamp-based secure file naming with original filename preservation
- QR modal with upload progress bar, mobile-responsive dashboard
- SQLAlchemy + SQLite, Docker containerized

`Flask` · `SQLAlchemy` · `qrcode` · `Docker`
